# 소설 설계 스튜디오 (MVP)

시놉시스, 인물, 플롯, 연대표, 목차/단락 집필을 한 화면에서 정리하는 정적 웹앱입니다.

## 바로 실행

### 방법 1) 파일로 바로 열기
- `index.html` 파일을 브라우저에서 직접 열면 동작합니다.

### 방법 2) 로컬 서버 실행 (권장)
```bash
python3 -m http.server 4173
```
- 브라우저에서 `http://127.0.0.1:4173/index.html` 접속

## 저장 방식
- 입력 중 자동 저장됩니다 (`localStorage`).
- 하단 `저장` 버튼 또는 `Ctrl+S` / `Cmd+S`로 즉시 저장할 수 있습니다.
- `JSON 내보내기`로 현재 작업 내용을 파일로 백업할 수 있습니다.
- `초기화`로 로컬 저장 데이터를 제거할 수 있습니다.
